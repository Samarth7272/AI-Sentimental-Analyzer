## 🎯 The Problem

Businesses receive huge amounts of customer feedback through social media, reviews and other online platforms. Reading it manually is slow and makes it hard to see overall customer opinion.

**AI Sentiment Analyzer** automates this. It classifies each piece of text, stores the results and visualizes the overall sentiment so decisions can be made quickly.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Samarth7272/AI-Sentimental-Analyzer.git
cd AI-Sentimental-Analyzer
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate it

```bash
# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
python app.py
```

If the app starts a web server, open the local URL shown in your terminal.
