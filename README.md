🚀 Project Overview

The AI Sentiment Analyzer is a Python-based application that helps understand people's opinions and emotions from textual data.

It analyzes text and classifies sentiment into categories such as Positive, Negative, and Neutral, depending on the implemented model.

The project aims to demonstrate how Artificial Intelligence and Natural Language Processing can help businesses understand customer feedback, product reviews, and public opinions.

🎯 Problem Statement

Businesses receive large amounts of customer feedback through social media, reviews, and other online platforms.

Manually analyzing this information takes time and makes it difficult to identify overall customer opinions.

This project explores an automated approach to sentiment analysis using Python and machine learning techniques.

⚙️ Installation & Setup

1. Clone the repository

git clone https://github.com/Samarth7272/AI-Sentimental-Analyzer.git

2. Navigate to the project

cd AI-Sentimental-Analyzer

3. Create a virtual environment

python -m venv venv

4. Activate the virtual environment

Windows:

venv\Scripts\activate

Linux / macOS:

source venv/bin/activate

5. Install dependencies

pip install -r requirements.txt

6. Run the application

python app.py

Open the local URL displayed in your terminal, if the application starts a web server.

🧪 Testing

Run the available test script:

python test.py
